## 🌌 Sobre o Projeto
Desenvolvido com um design **Sci-Fi / Cósmico**, o site oferece uma experiência imersiva aos clientes, destacando as especialidades da casa (pizzas tradicionais, esfihas gigantes de ~15cm e pizzas doces) com links diretos para o sistema oficial de delivery e WhatsApp das unidades.

---

## 🚀 Tecnologias Utilizadas
Este projeto foi construído utilizando os conceitos essenciais de **Front-End Moderno**:
* **HTML5 Semântico:** Estrutura limpa e organizada da página.
* **Tailwind CSS (via CDN):** Estilização rápida, responsiva e moderna com paleta de cores personalizada (`spaceBlack`, `cosmicDark`, `solarOrange`, `stellarGold`).
* **CSS3 Customizado (`style.css`):** Animações fluidas (como o giro suave do planeta) e efeitos de brilho customizados.
* **JavaScript Puro (`script.js`):** Interatividade dinâmica e redirecionamentos inteligentes para o fluxo de pedidos.
